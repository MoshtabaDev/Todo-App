# 📝 Todo App

A simple and practical application for **managing and tracking daily tasks**, designed and developed to practice and improve front-end development skills.

## ✨ Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* ✅ Manage task completion status
* 🔄 Dynamic updates without reloading the page
* 📱 Responsive design for different screen sizes and devices
* 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* React
